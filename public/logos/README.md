# Organization marks

All three organizations display their original logo colors at full opacity. Waterloo uses the official color and color-reversed variants for light and dark themes. Organization links use stronger, irregular marker strokes with theme-specific text colors.

- uwaterloo-color.png: high-resolution PNG from https://uwaterloo.ca/brand/sites/ca.brand/files/universityofwaterloo_logo_horiz_colour.zip
- uwaterloo-color-dark.png: high-resolution PNG from https://uwaterloo.ca/brand/sites/ca.brand/files/universityofwaterloo_logo_horiz_colour_rev.zip

Both color variants are linked from https://uwaterloo.ca/brand/uw-logos. Theme-specific blue and gold link text and translucent highlights complement the original logo colors while keeping text readable.

- uwaterloo-mark.png: https://uwaterloo.ca/brand/sites/ca.brand/files/universityofwaterloo_logo_horiz_bk.png, linked from https://uwaterloo.ca/brand/uw-logos.

Downloaded October 29, 2026. Decorative marks are aria-hidden; adjacent names provide the accessible label. No remote image requests are needed at runtime.

- ucalgary.svg: previous monochrome anniversary logo, retained as a source asset.
- ucalgary-color.svg: official full-color vector from https://arts.ucalgary.ca/themes/ucalgary/ucws_theme/images/UCalgary.svg. Only the viewBox is cropped to the shield (18.3, 18.8, 34.9, 44.5); the original vector paths and colors are retained. The same shield works on both themes.

- nexaquanta-hires.png: https://nexaquanta.ai/wp-content/uploads/2026/08/linkedin-square-scaled.png, the official 2560×2560 transparent mark linked as the organization logo in the homepage structured data. CSS preserves its original aspect ratio. The source asset is unmodified.
