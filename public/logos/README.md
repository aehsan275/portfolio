# Organization marks

These source PNGs are unmodified. CSS uses their transparency as a monochrome mask, tinted with the surrounding text color at 80% opacity. The Waterloo mask selects only the shield from the official horizontal black logo; the source wordmark is retained in the file.

- uwaterloo-mark.png: https://uwaterloo.ca/brand/sites/ca.brand/files/universityofwaterloo_logo_horiz_bk.png, linked from https://uwaterloo.ca/brand/uw-logos.
- nexaquanta.png: https://nexaquanta.ai/wp-content/uploads/2026/08/linkedin-square-150x150.png, the compact mark used by https://nexaquanta.ai/.

Downloaded October 29, 2026. Decorative marks are aria-hidden; adjacent names provide the accessible label. No remote image requests are needed at runtime.

- ucalgary.svg: https://www.ucalgary.ca/themes/ucalgary/ucws_theme/images/UCalgary_Anniversary.svg, served by https://www.ucalgary.ca/. The SVG source is retained unmodified. CSS selects the shield only (source bounds x76.39, y26.16, width24.64, height31.56) and applies the same currentColor mask and cap-height alignment as the other marks.

- nexaquanta-hires.png: https://nexaquanta.ai/wp-content/uploads/2026/08/linkedin-square-scaled.png, the official 2560×2560 transparent mark linked as the organization logo in the homepage structured data. Replaces the 150×150 mask in use. CSS retains the narrowed 1.5cap width and 1cap height, with mask crop offsets matched to the new source. The source asset is unmodified.
