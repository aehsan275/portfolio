# Product

## Platform

Web portfolio

## Purpose

A personal portfolio for recruiters and visitors exploring Abdullah's engineering work.

## Direction

The site uses a warm daytime palette and a matching moonlit theme, with a garden pavilion, traditional shopfronts, rooftops, and a kite game. Projects, reading, experience, and thoughts remain available as scroll-snapped chapters within one landing page. Desktop chapters fit one screen from 1280×720, with three project columns throughout desktop layouts. Selecting a kite starts play immediately, hides the portfolio text, and displays rounded bottom controls without popups. Kites have varied wind-driven flight and occasional tricks; elimination combat allows bots to cut each other and the player, with the last kite flying winning the round.

Top navigation returns to `/` when **home** is selected.

## Stack

React 19, TypeScript, Vite, Tailwind CSS 4, and daisyUI 5.
